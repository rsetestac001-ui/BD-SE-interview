本儲存庫是一份個人溫習彙編，用來準備屋宇署結構工程師（合約）（職位編號 50460）面試。它不是屋宇署的官方網站或出版物。

權威現行版本永遠以 [屋宇署](https://www.bd.gov.hk) 及 [香港電子法例](https://www.elegislation.gov.hk) 為準。
