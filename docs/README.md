# 屋宇署結構工程師（合約）面試參考文件

本目錄收集香港特別行政區政府的官方 PDF，供準備屋宇署結構工程師（合約）（職位編號 50460）面試使用。這是個人溫習彙編，不是屋宇署的出版物，亦沒有改寫或撮寫法例正文。

權威現行版本永遠以 [屋宇署](https://www.bd.gov.hk) 及 [香港電子法例](https://www.elegislation.gov.hk) 為準。文件如有更新，以該兩個網站當日公布的版本為準。檢索日期為 **2026年11月16日**。

收錄範圍對應審圖與同意、完工及佔用、地盤審核、僭建和危險建築物／斜坡／排水執法、強制驗樓及強制驗窗、消防安全改善工程的結構工作、小型工程，以及檢控、紀律與上訴。結構設計守則只收現行版本及其在屋宇署守則頁列出的修訂。作業備考沒有整套下載；官方索引約有二百二十份現行 PNAP，這裏只保留與上述職務直接相關的現行簽署版。

法例 PDF 是電子法例「具法律地位的核證文本」雙語整章合併版（含封面及制定史）。作業備考及強制驗樓驗窗備考是索引頁的現行簽署版；若中文索引註明暫只提供英文版本，則只存英文簽署版。

《小型工程監管制度技術指引（2024年修訂版）》PDF 約 139 MB，超過 GitHub 單檔 100 MB 限制，以 Git LFS 存放。複製本儲存庫後請執行 `git lfs pull`，否則該檔只會是指標檔。

版權說明見 [COPYRIGHT.md](COPYRIGHT.md)。機器可讀索引見 [sources.json](sources.json)。
